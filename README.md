# LELAN TECHNOLOGY

乐懒科技官方网站。

## Stack

- Next.js 16
- React 19
- TypeScript
- Tailwind CSS v4

## Development

```bash
npm install
npm run dev
```

## Verification

```bash
npm run lint
npx tsc --noEmit
npm run build
```

## Production model

Static export (`output: "export"`)

Build output: `out/`

## Node

`>=20.9.0`
